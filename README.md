# TimeWeaver

TimeWeaver — це веб-система для автоматизованого складання академічного розкладу занять. Проєкт вирішує класичну проблему розподілу навчального навантаження, враховуючи наявність аудиторій, груп, викладачів та їхніх побажань щодо часу проведення занять.

## Основний функціонал

- **Автоматична генерація розкладу:** Використання евристичного алгоритму з системою балів (Scoring) для оптимального розподілу пар.
- **Врахування жорстких обмежень (Hard Constraints):**
  - Викладач або група не можуть перебувати на двох парах одночасно.
  - Аудиторія не може приймати дві групи одночасно.
  - Врахування годин, позначених викладачем як "Неможливо" (Unavailable).
- **Врахування м'яких обмежень (Soft Constraints):**
  - Пріоритетне розміщення пар у "Бажані" (Preferred) години для викладача.
  - Відповідність типу аудиторії (комп'ютерний клас, спортзал тощо) вимогам дисципліни.
  - Перевірка місткості аудиторії відповідно до кількості студентів у групі.
- **Матриця побажань викладачів:** Зручний інтерфейс для налаштування доступності кожного викладача по днях тижня та номерах пар.
- **Різні режими перегляду:** Перегляд загального розкладу (офіційний документ) або фільтрація за конкретною групою, викладачем чи аудиторією.

## 🛠 Стек технологій

Проєкт побудовано за архітектурним патерном Application Factory (MVC) з використанням сучасних технологій:

- **Бекенд:** Python, Flask (з використанням Blueprints для маршрутизації)
- **База даних:** SQLite
- **ORM:** SQLAlchemy (Flask-SQLAlchemy)
- **Фронтенд:** HTML5, CSS3, Vanilla JavaScript, Jinja2 (серверний рендеринг)
- **Архітектура:** Модульна структура (Models, Routes)

## Структура бази даних

Система побудована на реляційній базі даних (`schedule.db`), яка включає 7 взаємопов'язаних сутностей:
1. `Group` (Групи)
2. `Teacher` (Викладачі)
3. `Classroom` (Аудиторії)
4. `Subject` (Дисципліни — зв'язує групу, викладача та вимоги до аудиторії)
5. `TimeSlot` (Часові слоти — розклад дзвінків)
6. `TeacherPreference` (Матриця побажань викладачів)
7. `ScheduleEntry` (Пара — головна таблиця, що генерується алгоритмом)

## Інструкція із запуску (Локально)

Переконайтеся, що на вашому комп'ютері встановлено Python 3.10+.

**1. Клонування репозиторію:**
git clone https://github.com/globo-glaber/TimeWeaver.git
cd TimeWeaver

**2. Створення та активація віртуального середовища:**
# Для Windows:
python -m venv venv
.\venv\Scripts\activate

# Для macOS/Linux:
python3 -m venv venv
source venv/bin/activate

**3. Встановлення залежностей:**
pip install Flask Flask-SQLAlchemy

**4. Запуск локального сервера:**
python run.py

Після запуску система буде доступна у браузері за адресою: `http://127.0.0.1:5000`

> **Примітка:** База даних (`schedule.db`) створиться автоматично при першому запуску програми. Якщо таблиці порожні, скористайтеся кнопкою "Демонстраційні дані" в інтерфейсі (якщо передбачено) або створіть сутності вручну через меню.
